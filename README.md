# Mosaic Tool

手動モザイク処理ツール。`input/` フォルダの画像を名前順に1枚ずつ表示し、ブラシ・消しゴム・魔法の杖・黒線ブラシでモザイク領域を指定して `output/` に保存する。

## セットアップ（初回のみ）

Python 3.10 が必要なのだ。

```
setup.bat
```

`venv/` を作成して Pillow・numpy を自動インストールするのだ。

## 起動

```
run.bat
```

## 使い方

1. `input/` フォルダに処理したい画像（PNG / JPG / JPEG / WEBP / BMP）を置く
2. `run.bat` を起動
3. 画像が1枚ずつ表示されるので、モザイクをかけたい箇所を塗る
4. 「完了 →」ボタンで `output/` に保存して次の画像へ

`output/` に同名ファイルが既にある画像は自動スキップされる。全画像を処理し終えるとダイアログを出して終了する。

`input/` と `output/` の中身をまとめて消したいときは `clear.bat` を使うのだ（`.gitkeep` は残る）。

## 操作一覧

| 操作 | 内容 |
|------|------|
| 左クリック / ドラッグ | 選択中のツールを適用 |
| ブラシボタン | 円形にモザイク塗り |
| 消しゴムボタン | 円形にモザイクを消す |
| 魔法の杖ボタン | クリック点の色を基準にフラッドフィルでモザイク化（ドラッグ不可・クリックのみ） |
| 黒線ブラシボタン | ドラッグした円内の暗い（黒線）ピクセルだけモザイク化 |
| 筆の太さ | 10 / 20 / 30 / 50 / 80 px から選択（魔法の杖以外で有効） |
| Undo / Ctrl+Z | 1操作戻す（マウスを押した時点のマスクへ戻る） |
| スクロール | ズームイン / アウト（マウス位置中心、0.05〜20倍） |
| 右クリックドラッグ | 画像をパン |
| 完了 → | `output/` に保存して次の画像へ |

ウィンドウをリサイズすると画像は自動でフィット表示に戻るのだ。

## ツールごとの調整スライダー

左のコントロールパネルからリアルタイムに変更できるのだ。

| スライダー | 範囲 | 初期値 | 内容 |
|------|------|-----|------|
| 色差 tolerance | 1〜100 | 25 | 魔法の杖が同色とみなす RGB の最大差 |
| 境界膨張 | 0〜200 | 25 | 魔法の杖の結果を広げる量（100 = 画像幅の 1/100 px） |
| 輝度しきい値 | 0〜255 | 80 | 黒線ブラシがこの輝度以下のピクセルを黒線とみなす |
| 膨張 | 0〜200 | 25 | 黒線ブラシの結果を広げる量（100 = 画像幅の 1/100 px） |

## モザイク仕様

| 項目 | 値 |
|------|-----|
| ブロックサイズ | 画像幅の 1/100（最小 4px） |
| 縮小 / 拡大方式 | 縮小 BOX → 拡大 NEAREST |
| 保存形式 | 入力と同じファイル名・拡張子で `output/` へ |

## 設定ファイル

`settings.json` でスライダーの起動時デフォルト値を変更できるのだ。

```json
{
  "wand_tolerance": 25,
  "wand_dilate_scale": 25,
  "line_threshold": 80,
  "line_dilate_scale": 25
}
```

| キー | 説明 | デフォルト |
|------|------|-----------|
| `wand_tolerance` | 魔法の杖の色差 tolerance（1〜100） | 25 |
| `wand_dilate_scale` | 魔法の杖の境界膨張スケール（0〜200、100 = 画像幅の 1/100 px） | 25 |
| `line_threshold` | 黒線ブラシの輝度しきい値（0〜255、この値以下を黒線とみなす） | 80 |
| `line_dilate_scale` | 黒線ブラシの膨張スケール（0〜200、100 = 画像幅の 1/100 px） | 25 |

ファイルが無い・JSON が壊れている場合はコード内のデフォルト値にフォールバックする。書かれていないキーだけデフォルトで補われるのだ。

## ディレクトリ構成

```
mosaic/
├── app.py            # メインアプリ
├── settings.json     # スライダーの初期値
├── run.bat           # 起動スクリプト
├── setup.bat         # 初回セットアップ（venv 作成・パッケージインストール）
├── clear.bat         # input / output のファイルを一括削除
├── requirements.txt
├── .python-version   # 3.10
├── input/            # 処理対象画像を置く（画像は git 管理外）
└── output/           # 保存先（画像は git 管理外）
```
