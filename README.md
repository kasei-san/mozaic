# Mosaic Tool

手動モザイク処理ツール。`input/` フォルダの画像を名前順に1枚ずつ表示し、ブラシ・消しゴム・魔法の杖でモザイク領域を指定して `output/` に保存する。

## 必要環境

- Python 3.10+
- Pillow
- numpy

```
pip install pillow numpy
```

## 起動

```
python app.py
```

## 使い方

1. `input/` フォルダに処理したい画像（PNG / JPG / WEBP / BMP）を置く
2. `run.bat` を起動
3. 画像が1枚ずつ表示されるので、モザイクをかけたい箇所を塗る
4. 「完了 →」ボタンで `output/` に保存して次の画像へ

`output/` に同名ファイルが既にある画像は起動時に自動スキップされる。

## 操作一覧

| 操作 | 内容 |
|------|------|
| 左クリック / ドラッグ | ブラシでモザイク塗り |
| 消しゴムボタン | モザイクを消す |
| 魔法の杖ボタン | クリック点の色を基準にフラッドフィルでモザイク化 |
| Undo / Ctrl+Z | 1操作戻す |
| スクロール | ズームイン / アウト（マウス位置中心） |
| 右クリックドラッグ | 画像をパン |
| 完了 → | output に保存して次の画像へ |

## モザイク仕様

| 項目 | 値 |
|------|-----|
| ブロックサイズ | 画像幅の 1/100（最小 4px） |
| 魔法の杖 tolerance | 50（RGB 最大差） |
| 魔法の杖 境界膨張 | 画像幅の 1/100 px |

## ディレクトリ構成

```
mosaic/
├── app.py          # メインアプリ
├── run.bat         # 起動スクリプト
├── requirements.txt
├── input/          # 処理対象画像を置く（git 管理外）
└── output/         # 保存先（git 管理外）
```
